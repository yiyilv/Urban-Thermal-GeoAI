## Checks before making stronger claims

- **Thermal interpretation:** LST is a clustering input. Temperature separation within the fitted clusters is descriptive. An LST-excluded analysis or independent thermal observations would be needed to assess independent thermal relevance. Report physical temperature differences only after confirming the source units and transformations.
- **Stability:** Compare multiple random seeds and, if claiming wider applicability, another season or area. Cluster IDs and colours are arbitrary across fits; align clusters by their profiles before comparing labels.
- **Spatial dependence:** Neighbouring raster cells are not independent samples. Ordinary chi-square p-values should not be used as independent-sample significance evidence. Association metrics and cross-tabulations here are descriptive.
- **Input semantics:** Confirm that the two accepted stack filenames represent the same masking and scaling conventions. The current code checks the band order, resolution and CRS, but these checks do not establish physical units or preprocessing equivalence.

For a small portfolio example, recover the minimum result package first. Additional model complexity is not necessary to explain the existing PCA/K-means workflow clearly.
